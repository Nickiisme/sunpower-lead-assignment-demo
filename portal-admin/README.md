# SunPower Portal Admin Lead Management Demo

Static demo with synthetic data. Open index.html locally, or serve this folder over HTTP.

- Company summary and read-only Lead details with company, partner code, company country and company sales representative filters.
- Stage completion, invalid lead and final Converted rates; average first follow-up and closure times in rounded hours.
- Click Total leads to open all visible leads for that company.
- Enabled countries opens a centered dialog; selections are stored only in this browser.
- Bundled Lexend Deca fonts; Portal Admin UI v2.3 styling.

This demo does not connect to production APIs, permissions, customer data or country configuration.
